# Band charter outreach pipeline

A PostgreSQL lead pipeline built for a band travel charter client: East
Coast schools filtered down to traveling band programs, music-department
contacts found through parameter testing, and queries chained into
soft-lead scoring and templated email generation.

## Stack

Python, PostgreSQL, SQL.
